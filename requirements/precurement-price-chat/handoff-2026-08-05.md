## Data Contract

The workbook is authoritative for:

- product/source descriptions
- quantity tiers
- vendor quotes
- awarded price
- awarded vendor
- source row/cell trace

The LLM is not allowed to create or modify price, quantity, vendor, or award facts.

The index preserves both:

- `awarded_price`: the awarded value from the workbook
- `lowest_quote_price`: deterministic minimum of numeric vendor quotes

These values are intentionally separate. In the current source, some awarded prices are not equal to the mathematical minimum vendor quote.

Important current source observations:

- 49 rows have no quantity value
- 11 rows have no numeric awarded price after normalization
- raw source values are retained; no missing values are invented
- source export contains no `#REF!` or `#N/A` leakage

## LLM Enrichment

The enrichment cache contains:

- 179 logical product records
- model: `deploy-gpt-5.4-mini`
- 176 records with product specs
- 116 records with product conditions
- all 518 indexed rows resolve to enrichment status `accepted`
- cache is keyed by logical product and source input hash
- cache is checkpointed after each successful record, so interrupted runs can resume

Enrichment fields include:

- `product_name`
- `product_aliases`
- `product_type`
- `keywords`
- `product_specs`
- `product_conditions`

Each spec/condition requires source evidence and confidence. Evidence validation allows harmless punctuation/spacing differences and common connector words, but source facts are still required.

The source JSON is not modified by enrichment.

## Pipeline Commands

Run from the repository root. Azure Search and Azure OpenAI endpoints are private/VNet-connected in the deployed environment. Use a host with the required network path.

Validate without Azure changes:

```bash
python3 requirements/precurement-price-chat/scripts/sync_azure_ai_search.py --dry-run
```

Generate or resume LLM enrichment:

```bash
set -a
source docker/.env.owui
set +a
python3 requirements/precurement-price-chat/scripts/sync_azure_ai_search.py --enrich
```

Create or update the index schema:

```bash
set -a
source docker/.env.owui
set +a
python3 requirements/precurement-price-chat/scripts/sync_azure_ai_search.py --create-or-update
```

Ingest the current catalog:

```bash
set -a
source docker/.env.owui
set +a
python3 requirements/precurement-price-chat/scripts/sync_azure_ai_search.py --ingest
```

Verify schema, vector dimensions, count, and semantic sample search:

```bash
set -a
source docker/.env.owui
set +a
python3 requirements/precurement-price-chat/scripts/sync_azure_ai_search.py --verify
```

For a normal full refresh after changing the source export:

```bash
set -a
source docker/.env.owui
set +a
python3 requirements/precurement-price-chat/scripts/sync_azure_ai_search.py \
  --enrich --create-or-update --ingest --verify
```

The pipeline uploads with `mergeOrUpload`, uses bounded batches, paginates existing IDs, and deletes stale documents only inside the procurement dataset.

`--force-recreate` exists but is destructive. Use it only for the target `procurement-catalog-v1` index after an explicit schema decision. It is not required for normal updates.

Legacy cleanup can be checked safely with:

```bash
set -a
source docker/.env.owui
set +a
python3 requirements/precurement-price-chat/scripts/sync_azure_ai_search.py --delete-legacy
```

The command only checks/deletes the two exact allowlisted legacy names.

1. queries only `procurement-catalog-v1`
2. performs hybrid/vector/semantic retrieval
3. filters quantity tiers deterministically
4. groups results by `logical_item_id`
5. returns authoritative awarded price/vendor and vendor quote data
6. asks the LLM to clarify missing product specifications
7. never calculates or invents a price not present in the index/source

Do not restore the old v2 schema or old tool blindly. Use the current row-level schema and this pipeline as the contract.
