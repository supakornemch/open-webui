💬 แชทกับ Genie

  • เปิด New Chat — เลือกโมเดลจาก dropdown ด้านบน
  • พิมพ์คำถามเป็นภาษาไทยหรืออังกฤษก็ได้
  • Genie ค้นหาจากฐานข้อมูลเอกสารภายในก่อนตอบ
  • คำตอบจะอ้างอิงชื่อเอกสารต้นทาง

📎 แนบไฟล์ถาม

  • ลากไฟล์ PDF, Excel, Word, CSV มาวางในแชท
  • Genie อ่านเอกสารให้ แล้วถามรายละเอียดได้เลย
  • ลอง: "สรุปเอกสารนี้ให้หน่อย" หรือ "หาข้อมูลเกี่ยวกับ X ในไฟล์นี้"

📎 แนบไฟล์ถาม — ตัวอย่าง Use Case

อัปโหลดไฟล์ CSV ยอดขาย แล้วให้ Genie สร้าง HTML Preview แบบ Bar Chart ให้ดูทันที:

  1. ลากไฟล์ sales.csv มาวางในแชท
  2. พิมพ์คำสั่ง: "สร้าง HTML preview แสดงยอดขายแยกสาขาแบบ bar chart จากไฟล์นี้ให้หน่อย"
  3. Genie อ่านไฟล์ → เขียนโค้ด Chart.js → แสดงผลในแชท

📊 ตัวอย่าง: CSV → HTML Preview

📚 Knowledge Base

จัดการฐานความรู้ (Knowledge Base) สำหรับให้ Agent ใช้อ้างอิง

📖 Knowledge Base คืออะไร?

Knowledge Base (KB) คือคลังเอกสารที่ Agent สามารถดึงมาอ่านเพื่อตอบคำถามได้ — เหมือนมีแฟ้มเอกสารไว้ให้ AI ค้นหา

  • รองรับไฟล์: PDF, DOCX, TXT, CSV, MD
  • สามารถอัปโหลดทีละไฟล์ หรือทั้งโฟลเดอร์
  • เนื้อหาจะถูก chunk และ embed เป็น vector อัตโนมัติ
  • เวลาถาม Agent จะค้นหาที่ KB ก่อน แล้วค่อยตอบ

1 ไปที่ Workspace → Knowledge

คลิก Workspace → Knowledge — จะเห็นรายการ Knowledge Bases ที่สร้างไว้

2 สร้าง Knowledge Base ใหม่

  • กด New Knowledge → ตั้งชื่อ เช่น MFA Setup Guide
  • เลือก Public เพื่อให้ทุกคนใช้งานได้
  • กด Create Knowledge → จากนั้นอัปโหลดไฟล์ PDF/DOCX

3 ใช้ Knowledge ในแชท

เมื่อมี Knowledge Base แล้ว สามารถแนบมาใช้ในแชทได้ดังนี้:

  • กดปุ่ม More (⋯) ในช่องพิมพ์ข้อความ
  • เลือก Attach Knowledge
  • เลือก Knowledge Base ที่ต้องการ (เช่น MFA Setup Guide)
  • Knowledge จะถูกแนบในแชท — พิมพ์คำถามได้เลย

4 ตัวอย่าง: ถามเกี่ยวกับ MFA

เมื่อแนบ Knowledge "MFA Setup Guide" แล้ว พิมพ์คำถามเช่น "ตั้งค่า MFA ในมือถือยังไง" → Genie จะค้นหาจากเอกสารและตอบพร้อมอ้างอิง

💡 แนะนำ

✅ ใช้กับ Agent Enterprise

  • ประกาศ HR, ระเบียบ, คำสั่ง
  • คู่มือ IT, นโยบายความปลอดภัย
  • เอกสาร Open WebUI

⚠️ ข้อควรรู้

  • ขนาดไฟล์ไม่ควรเกิน 50MB
  • ชื่อไฟล์ควรสื่อความหมาย (อังกฤษ)
  • KB ที่อัปเดตแล้วต้องรอ re-index

📎 แนบไฟล์แล้วถาม — ตัวอย่าง

นอกจากการใช้ Knowledge Base แล้ว คุณสามารถอัปโหลดไฟล์ตรงในแชทได้ทันที:

  • ลากไฟล์มาวาง หรือกดปุ่ม + (Attach) ในช่องพิมพ์
  • รองรับ: PDF, Excel, Word, CSV, รูปภาพ
  • พิมพ์คำถามเกี่ยวกับไฟล์ เช่น "สรุปเอกสารนี้ให้หน่อย"
  • Genie จะอ่านเนื้อหาและตอบพร้อม Reference ไปยังส่วนที่เกี่ยวข้อง

💬 Prompts

จัดการ Prompt Templates สำหรับเรียกใช้ซ้ำได้

📝 Prompts คืออะไร?

Prompts คือ เทมเพลตคำสั่ง ที่เซฟไว้ใช้กับ Agent ได้ทันที โดยไม่ต้องพิมพ์ซ้ำ — คล้ายๆ กับ shortcut คำสั่ง

# ตัวอย่าง Prompt Template
ชื่อ: สรุปเอกสาร
Prompt: ช่วยสรุปเอกสารต่อไปนี้เป็นภาษาไทย
  แบบ bullet points แยกเป็นหัวข้อ:
  1. ใจความสำคัญ
  2. รายละเอียด
  3. ข้อควรปฏิบัติ
  {content}

1 ไปที่ Workspace → Prompts

คลิก Workspace → Prompts — จะเห็นรายการ Prompt Templates ที่สร้างไว้

2 สร้าง Prompt

  • Prompt Name: ตั้งชื่อที่จำง่าย (เช่น สรุปเอกสาร, ค้นหาเอกสาร)
  • Command: พิมพ์ /summarize หรือ /search เพื่อใช้ในแชท
  • Prompt Content: ข้อความคำสั่ง ใช้ {{variable}} เป็นตัวแปร

3 ใช้งาน Prompt ในแชท

  • ในช่องแชท พิมพ์ / (Slash) → จะเห็นรายการ Prompts ทั้งหมด
  • คลิกเลือก Prompt ที่ต้องการ — ข้อความคำสั่งจะถูกแทรกให้อัตโนมัติ
  • กรอกตัวแปร (ถ้ามี) แล้วกด Enter
  • ตัวอย่าง: พิมพ์ /summarize → Genie จะถามว่าให้สรุปอะไร → แนบไฟล์หรือวางเนื้อหา → ได้สรุปทันที

🤖 ขั้นตอนสร้าง Agent

สร้าง Model ที่มี Tool ติดตัว — พร้อมใช้งาน

1 Workspace → Models → เลือก Model

คลิก Workspace → Models → เลือก model ที่ต้องการ (เช่น deploy-gpt-5.4-mini) หรือสร้างใหม่

2 เปิด Tools

เลื่อนลงมาที่ส่วน Tools → ค้นหา → เลือก "Enterprise Search"

จากนั้นเลือก Native Mode (Agentic Mode) — model จะเรียก Tool อัตโนมัติเวลาต้องการค้นหาเอกสาร

3 Save

กด Save → กลับมาดู Models list จะเห็น Model พร้อมใช้งาน

🧠 Skills

จัดการ Skill set ให้ Agent — ความสามารถพิเศษนอกเหนือจาก Built-in

🧩 Skills คืออะไร?

Skills คือ ความสามารถเฉพาะทาง ที่เพิ่มให้ Agent ได้ เช่น การคำนวณขั้นสูง, การดึงข้อมูลจาก API ภายนอก, การทำงานกับระบบเฉพาะ

  • ต่างจาก Tools — Skills จะถูกเรียกใช้ อัตโนมัติ โดย Agent (ไม่ต้องเลือกเอง)
  • เป็นเหมือน "พรสวรรค์" ที่ Agent มีติดตัว
  • สร้างด้วยภาษา Python เช่นเดียวกับ Tools

1 ไปที่ Workspace → Skills

คลิก Workspace → Skills — จะเห็น Skills ที่สร้างไว้

2 สร้าง Skill

  • Skill Name: ชื่อ Skill (เช่น Thai Date Converter)
  • Skill ID: thai-date-converter
  • Description: อธิบายว่า Skill นี้ทำอะไร
  • Instructions: เขียนคำแนะนำในรูปแบบ Markdown — บอกวิธีการทำงานให้ Agent ทำตาม

เวลา สร้าง/แก้ไข Model (Workspace → Models):

  • เลื่อนลงมาที่ส่วน Skills
  • ค้นหาและเลือก Skill ที่ต้องการ
  • Agent จะใช้ Skill โดยอัตโนมัติเมื่อเจอคำถามที่ตรง

🔧 ขั้นตอนเพิ่ม Tool (Advance)

สร้าง Tools เองด้วย Python — ตัวอย่าง: Calculator Tool

🧰 Tools คืออะไร?

Tools คือ ฟังก์ชัน Python ที่ Agent สามารถเรียกใช้ได้ — เหมือนให้ Agent มีเครื่องมือติดตัว

  • เขียนด้วยภาษา Python ล้วน ๆ (คืนค่าเป็น string)
  • Agent จะเรียก Tool อัตโนมัติเมื่อเจอคำถามที่ตรงกับ description
  • แปะโค้ดลงใน Editor แล้ว Save — พร้อมใช้งานทันที

1 ไปที่ Workspace → Tools

คลิก Workspace → Tools → กด New Tool

2 กรอกข้อมูล + วางโค้ด

  • Tool Name: Calculator
  • Tool ID: calculator
  • Description: คำนวณผลลัพธ์ของนิพจน์ทางคณิตศาสตร์
  • วางโค้ดด้านล่างใน Code Editor → Save → Confirm

3 โค้ด Calculator Tool

คัดลอกโค้ดด้านล่าง — รองรับ +, -, *, /, sqrt, pow, abs, floor, ceil

"""
title: Calculator
author: Haadthip DIO
version: 1.0
"""

import math
from pydantic import BaseModel, Field

class Tools:
    class Valves(BaseModel):
        pass

    def __init__(self):
        self.valves = self.Valves()

    def calculator(
        self,
        expression: str = Field(
            ...,
            description="Mathematical expression เช่น 2+2, sqrt(16), 3*4+2"
        ),
    ) -> str:
        """
        คำนวณผลลัพธ์ของนิพจน์ทางคณิตศาสตร์
        """
        allowed = set("0123456789+-*/.() sqrtpowabsfloorceil")
        if not all(c in allowed for c in expression):
            return "⚠️ อนุญาตเฉพาะตัวเลขและ operator พื้นฐาน"

        try:
            result = eval(expression, {"__builtins__": {}}, {
                "sqrt": math.sqrt, "pow": math.pow,
                "abs": abs, "floor": math.floor, "ceil": math.ceil
            })
            return f"{expression} = {result}"
        except Exception as e:
            return f"⚠️ error: {e}"
